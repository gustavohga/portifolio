# 👨‍💻 Portfólio Pessoal | Gustavo Aguiar

> **Status:** Concluído / Em constante evolução

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar minha trajetória, experiências, competências e projetos como **Desenvolvedor Back-End**. 

O site foi construído com foco em performance e simplicidade, utilizando tecnologias nativas e design responsivo, sem a dependência de frameworks pesados no front-end.

## 🚀 Tecnologias Utilizadas

A estrutura do site foi desenvolvida 100% com tecnologias web padrão:

*   **HTML5:** Semântica estrutural e acessibilidade.
*   **CSS3:** Variáveis nativas (Custom Properties), CSS Grid, Flexbox e animações fluidas (incluindo tratamento para `prefers-reduced-motion`).
*   **JavaScript (Vanilla):** Lógica simples para interatividade do menu mobile e navegação suave (Smooth Scroll).
*   **Tipografia:** Space Grotesk, Inter e IBM Plex Mono (via Google Fonts).

*Nota: O design e a estrutura inicial contaram com o auxílio de IA, conforme referenciado no banner superior da página.*

## 🧩 Estrutura da Página

O portfólio é um site *Single Page Application* (SPA) estático, dividido nas seguintes seções:

1.  **Hero:** Apresentação inicial, status atual de carreira e estatísticas rápidas.
2.  **Sobre:** Minha trajetória, vindo da eletrônica para o desenvolvimento de sistemas, e formação acadêmica.
3.  **Experiência:** Histórico profissional e cursos extracurriculares (Cybersecurity, Python, Java).
4.  **Competências:** Minha stack tecnológica focada em Back-End (Java, Python, JS/TS, Spring, Flask, NestJS, Bancos de Dados) e conhecimentos em React.
5.  **Projetos:** Destaque para projetos full stack e envolvendo IoT, como o **DOMESTIX**.
6.  **Contato:** Links rápidos para e-mail, telefone, LinkedIn e GitHub.
